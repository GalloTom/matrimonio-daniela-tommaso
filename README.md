# Daniela & Tommaso — sito del matrimonio

Sito statico e responsivo per il matrimonio di Daniela e Tommaso del 22 maggio 2027.

## Pagine

- `index.html`: homepage con le informazioni principali.
- `rsvp.html`: modulo Google RSVP incorporato.
- `regali.html`: elenco delle idee regalo.
- `regalo.html`: dettaglio della singola idea regalo e coordinate bancarie.

## Aggiornare le idee regalo

Le idee sono raccolte nel file `assets/js/gifts.js`. Per aggiungerne una è sufficiente duplicare un elemento dell’elenco e modificare identificativo, titolo, testi e immagine.

## Prima della pubblicazione

1. Sostituire IBAN e BIC/SWIFT segnaposto in `regalo.html` con quelli definitivi e verificare l’intestatario.
2. Controllare se il modulo Google deve continuare a richiedere l’accesso a un account.
3. Verificare testi, data, orario e indirizzo.
4. Pubblicare tramite GitHub Pages soltanto dopo l’approvazione finale.

Il progetto non richiede installazioni o compilazioni: tutti i file possono essere pubblicati direttamente tramite GitHub Pages.
